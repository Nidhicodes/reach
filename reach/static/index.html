The Cypher

      

    

    

      
Reach Gateway is an MCP proxy between an agent and its real MCP servers. Every call is checked against this task's earlier calls, which live in FalkorDB, so taint follows a handoff to another agent. Runs here use real MCP to sandboxed mock servers; each scenario runs with the gateway in audit mode, then enforcing.
